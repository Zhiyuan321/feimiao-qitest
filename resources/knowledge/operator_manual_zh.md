# QITest 01 飞秒质谱工作站本地操作知识

## 主流程
软件的主流程是准备、采集、分析、复核与报告。“采集与分析”中央依次显示 TIC、质谱图、EIC，右侧仪器区显示关键状态。筛查结果统一在“生成报告”中复核，不在采集页重复放表格。没有数据时先核对仪器状态和活动方法，再由操作人员明确开始检测。AI 可以带用户到准备位置，但不能绕过确认直接启动真实采集。

## 采集与分析（原运行方法）
“采集与分析”用于进入当前活动方法对应的采集流程和查看三类曲线，不是修改方法参数。开始前检查设备连接、真空度、温度、载气、离子源和方法版本。开始检测、停止检测、重新检测共用页眉按钮。模拟适配器只用于开发演示，不能代表真实仪器已验证。开始、停止、降温、关机等高风险动作必须由操作人员确认并受权限和互锁约束。

## 方法版本
“方法”页面用于查看、创建和激活方法版本。已保存版本不可覆盖，每次修订生成新版本并保留校验值、创建人和时间。真实采集参数只有在通信协议、单位、范围和安全互锁确认后才能加入。

## 检测记录与数据
顶部“检测记录”用于管理历史检测。参考谱库和定量曲线放在“设置 → 标准与校准”。检测记录保存在本地 SQLite 工作区，可恢复当次谱图、候选证据和质量检查。导入一批检测数据时选择本软件支持的 .qit.json 归档；可多选，重复内容不会反复新增。任意厂商文件并不自动兼容。导出检测数据保留可复核的归档内容，PDF 报告在生成报告页面导出。AI 打开页面不代表已经完成导入、导出或生成文件，必须以实际文件和完成提示为准。

## 参考谱库
参考谱库中的“公共谱库”支持按物质名称、CAS 或分子式只读检索。“我的标准”独立保存用户资料，可新建和修改标准、读取 mz,intensity 两列 UTF-8 谱点 CSV，或导入导出 qstd.json。名称、离子化方式、来源为必填；母离子、定性离子、定量离子和内标标记按真实资料填写，不猜测。相同内容导入会去重，过期编辑不会覆盖较新的修订。用户标准尚未自动关联检测方法和鉴定管线；保存资料不等于已经验证适用性。谱库匹配只产生候选证据，不等于物质鉴定结论。

## 定量曲线
定量曲线可导入浓度、响应两列 CSV，表头为 concentration,response 或 浓度,响应；内标采用 concentration,response,internal_concentration,internal_response 四列，并明确填写内标名称和统一单位。至少三个参与点由本地 C++ 确定性引擎拟合，内标以浓度比和响应比计算。可选无权重或 1/x²；后者不接受零浓度，不自动删掉空白点。双击原点支持科学计数法，取消勾选只排除拟合、不删除数据。“计算样品浓度”仅接受校准范围内的响应，禁止外推。保存曲线生成含原点、单位和设置的 qcal.json，之后可从“更多”重新打开；CSV 导出仅含选中点。缺少校准不从定性候选推算浓度。自动内标配对与批量定量未实现，适用性和不确定度仍需人工确认。

## 生成报告
“生成报告”打开报告工作区。完成检测后选择需要写入报告的候选项，先复核再导出。报告必须保留记录编号、方法、操作人员、质量状态和证据边界。演示结果不构成海关鉴定结论。

## 仪器状态与仪器设置
“仪器”菜单把高频查看和低频维护分开：查看仪器状态会展开右侧监控区；仪器控制、参数预设和全部设置与维护进入设置工作区。设置页面按任务分组，不按技术模块堆叠。没有正式协议的控制项只显示状态和缺口，不伪造可执行能力。

“查看全部仪器参数”进入“仪器配置 / 运行状态”，显示同一仪器适配器提供的分子泵转速、电流、电压和温度，真空度，载气模式、气压和流速，离子阱与 TD 温度，离子源与倍增器电压，抽气流量和注射泵余量。主页右栏只保留关键值与异常，完整参数不重复堆在首屏。模拟数值只用于界面和数据链验证，不能作为真实仪器读数。

## 降温与关机
降温与关机是受控流程：先停止采集并保存记录，再启动降温并监测温度，达到仪器协议要求后才能关机。当前模拟适配器只保存演示状态，不会关闭真实仪器或电脑。真实硬件必须加入工程师权限、互锁和设备协议确认。

## 本地智能台

智能台可理解“打开报告”、“带我看仪器状态”、“去定量曲线”等口语请求。常用说法先由 C++ 确定性路由，其他明确的页面请求可由本地模型提出工具调用，但必须通过白名单和置信度检查。每次操作都会在界面中给出回执，无法执行时也会说明原因。

“调高一点”、“直接开始”等含糊或高风险请求不会由模型直接执行。智能台可打开相应设置或运行准备页，显示当前值、仪器约束和安全范围，最后的参数修改、采集、复核、降温与关机由有权限的人员确认。
智能台同时承担操作入口和说明书助手。输入“我要生成报告”“带我运行方法”“查看仪器状态”“打开定量曲线”等指令会通过 C++ 白名单执行界面操作；普通问题由本地知识检索和千问模型回答。AI 不直接计算科学数值，也不能修改候选为阳性、删除记录或绕过权限。

## 数据不足或没有数据
没有数据不是错误。在采集与分析页确认设备与方法，必要时从检测记录导入归档，或开始一次经确认的检测。报告和定量页面会说明缺少的输入，不用假数据填满界面。AI 应解释当前缺口并带用户到正确入口。

## 故障与稳定性
遇到异常时先保存当前记录，查看仪器关键状态和质量门控，再导出脱敏诊断包。不要反复强制启动采集。软件的核心采集、分析、记录和报告在 AI 不可用时仍应离线运行；AI 失败不能阻塞仪器控制台。

## 深度问答
只配置一个 Qwen3.5-4B-Q4_K_M 大模型，不存在开关前后 Q1 变 Q4 的切换。关闭深度问答时，由 C++ 本地指令引擎处理明确操作、检索操作说明和读取当前状态。开启后，复杂问题才按需加载同一模型。关闭会卸载推理进程，模型文件仍保留在硬盘，普通功能可以继续使用。第一次加载或老电脑推理可能较慢；内存不足时不会挤占资源强行启动。普通助手不是另一个训练出来的小语言模型，不保证理解任意口语。

## 离子源
离子源的实际状态与设定在“设置 → 离子源”。问“怎么打开离子源”只提供说明，不等于要求开机。明确开启或关闭请求先识别对象；真实仪器必须在页面核实安全约束，由有权限的操作人员确认并等待设备回执。模拟适配器只能改变模拟状态。分子源可作为口误提示，但不会因此猜测其他泵、阀或高压参数。“关闭它”没有明确对象时不会执行。

## 参数预设
在“设置 → 仪器配置 → 参数预设”编辑离子阱温度、进气流速、抽气流速和 EFC。输入有单位和范围，保存预设不代表真实硬件已经接受这些参数。不要用“高一点”猜出数值；应说明具体参数、目标值和单位，再按厂家允许范围核对。

## 调谐与校准
在“设置 → 仪器配置 → 调谐与校准”查看仪器校准入口。质量轴校准与浓度响应的定量曲线是不同任务。定量拟合在“设置 → 标准与校准 → 定量曲线”；没有厂家协议和真实标准样本，不能声称完成真实仪器调谐。

## 进样与注射泵
入口是“设置 → 仪器配置 → 进样与注射泵”。进样量、速度、方向和单位必须与实际设备协议一致。打开页面不会自动推液或启动泵；没有正式适配器时无法确认真实动作成功。

## 载气节省
在“设置 → 载气节省”查看载气模式。载气压力读数不等于流量，也不能在没有厂家范围时判断过载。不要因为一个压力读数自动关闭泵或阀，应先核实连接、单位和实测值。

## 清洗模式
清洗流程在“设置 → 清洗模式”；抽取清洗液是独立动作。使用前核对液体、气路和厂家操作顺序。智能台只能定位已提供的入口；尚未接入的真实动作不能用页面状态冒充已执行。

## 会话保护
“设置 → 锁屏”用于防止误触，进入后需要按“恢复操作”返回。它不是 Windows 系统锁屏，也不是密码认证；不会替代仪器安全互锁，不应该用来停止正在进行的检测。

## 校准公式与标准谱图导入边界
当前定量页面接受浓度响应校准点，由 C++ 做确定性线性拟合并人工复核。公共谱库只读；我的标准支持明确格式的谱点和标准资料管理，但任意公式、任意厂家二进制谱图并非已经支持导入。每份标准文件最多 1 MiB、10000 谱点，资料库最多 10000 条，列表每页 50 条。导入小型标准资料不等于训练或修改千问权重，不能自动作为正式鉴定依据。

## TIC 与质谱图
TIC 是每次扫描所有离子信号之和随采集时间的变化；质谱图是单次扫描按 m/z 展示的强度分布；EIC 是指定 m/z 窗口的信号随时间变化。导入 time_s,ms_level,mz,intensity 四列扫描 CSV 或带 scans 的 QITest 归档后，从检测记录打开，可查看 MS1 TIC；点击 TIC 或 EIC 时间点查看对应原始 MS1 质谱，点击质谱峰或填写 EIC 的 m/z 和 ±Da 提取窗口。TIC 旁“提取 / 积分”可选择 TIC、BPC、EIC 和扫描级别，保存积分记录。面积是原始强度乘秒，不直接当作浓度。无时间戳的旧谱图仍显示三图位置，但 TIC/EIC 显示等待时间序列，不生成假曲线。筛查结果在生成报告页，属于记录分析谱，不等于整条时间序列已完成多组分鉴定。

## 保存与恢复积分
在“提取 / 积分”中选择曲线、时间边界和基线方式，点击计算积分，再从“积分记录 → 保存积分结果”生成 qint.json。记录保存精确曲线、提取参数和面积，不替代原始扫描归档。参数变化后要重新计算才能保存。打开对应检测记录后，用“积分记录 → 恢复积分结果”重算验证并与当前扫描核对；不匹配或损坏时保留原状态。扣除端点直线基线采用有符号面积，不把负面积改成零。积分不是浓度，没有经过验证的校准不能用于浓度结论。
