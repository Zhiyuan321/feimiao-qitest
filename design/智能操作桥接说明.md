# 本地 AI 操作桥梁

## 目标

智能台既能解释说明书和当前证据，也能把自然语言转换成工作站内的受控操作。大语言模型不直接持有仪器接口、数据库连接或 QWidget 指针。

## 固定链路

```text
用户自然语言
  -> 意图识别（可替换）
  -> 白名单命令描述
  -> 权限、仪器状态和风险门控
  -> QAction / AppController
  -> 结构化执行结果
  -> 智能台回写
```

当前版本先由 `AiCommandRouter` 处理高频页面操作，能够容忍“帮我打开”“带我去”“我想查看”等自然表达。低风险页面跳转即时执行；开始采集、修改结论、删除记录、降温和关机不允许由语言模型直接执行。

## 统一交互结果

模型和本地规则路由共用同一套结果语义，避免“能聊天但不能操作”或“执行后没有反馈”：

- **解释**：读取当前页面、当前记录、仪器遥测和帮助索引，给出可追溯说明，不改变状态。
- **跳转**：打开明确的页面或侧栏，并回写实际到达位置。
- **执行**：仅执行白名单中的低风险、可回读动作；执行后必须读取新状态并回写结果。
- **确认**：对采集、硬件参数、离子源、降温、关机、结论和删除等动作，先定位界面并显示目标值、当前值、允许范围、风险和操作人，由用户确认后交给 C++ 引擎。

上下文按需构建，不把整个数据库塞入模型。最小上下文包含当前页面 ID、选中对象 ID、流程状态、权限、关键遥测、未处理告警和可用 action ID；对话中不得展示模型文件名、量化格式、提示词或内部路由字段。

## 下一阶段接口

模型升级时只替换“意图识别”适配器，并统一输出受约束的结构化提案：

```json
{
  "action": "open_report",
  "arguments": {},
  "confidence": 0.96
}
```

桥梁只接受已注册 action；未知字段、越权参数和硬件关键命令一律拒绝。需要确认的动作先生成可读预览，由操作员在界面中确认后再交给 C++ 引擎执行。科学计算结果始终来自确定性数据引擎，模型只负责理解、检索、协调和解释。

## 稳定性边界

- AI 服务退出、超时或模型替换时，仪器控制、采集、分析、复核和报告保持可用。
- 所有可执行命令必须有稳定 ID、参数模式、风险等级、权限要求和审计结果。
- 对话历史有容量上限；模型上下文从当前实验状态按需重建，不将半年运行数据全部塞入提示词。
- 界面只显示用户需要理解的状态，不显示模型文件名、量化格式或内部路由术语。
