# 轻量助手与固定菜单

Mac 默认 1024×768 客户区窗口，Windows 默认全屏。F11 或视图页可切换。菜单使用仪器控制、分析校准、系统三个固定组，不再把所有条目挤在一列。1024×700、1024×768 的菜单与默认监控无纵向滚动已由测试验证；数据表、聊天和部分长编辑弹窗仍允许内部滚动，不隐藏不可达内容。

窗口标题为“飞秒质谱工作站 · 4:3 轻量版”。若仍看到“仪器屏布局”、独立硬件接入说明和很长的设置列表，需保存编辑后退出旧进程，再打开交付目录中的应用。

## 模型选择与边界

当前更新：按用户要求改为 Qwen3.5-0.8B Q4_0，563036064 字节，SHA256 57d1997790d1744fba5b40a7317df71ea5e2acee28c47e78f0cce39c0703f8cf。来源 https://huggingface.co/ggml-org/Qwen3.5-0.8B-GGUF ，镜像下载后与来源公布的 SHA256 比对一致。许可在 ai/Qwen3.5-LICENSE。

同一短问答测试：Mac 加载 1.02 秒、总计 1.29 秒；Windows 程序在 Wine 下加载 3.02 秒、总计 6.00 秒。回答“打开报告工作区。”只是简短提示，不能代替完整手册，也不代表准确率或老电脑速度保证。保留按需加载、两线程、无模型工具调用的限制。下文 2.5 型号与测试为被替换前的历史记录，不再是当前默认。

本轮调谐/校准页统一主题分页、并排选择框和青绿色主按钮；1024×768 截图确认底部按钮可见，14 项原生 UI 测试通过。固定分组菜单不再保留原长列表；Mac 允许长宽分别调整，最小客户区 1024×700。

选用 Qwen2.5-0.5B-Instruct Q4_K_M，官方 GGUF 大小 491400032 字节，SHA256 为 74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db。

官方来源：https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/blob/main/qwen2.5-0.5b-instruct-q4_k_m.gguf 。直连下载超时后使用 hf-mirror 下载，并与官方公布哈希独立比对；许可证随交付包保留。

选择依据：纯文本小规模、官方已有 GGUF、现有 Win7 llama.cpp 可直接加载。相较于 4B 更侧重减少资源占用；未进行全型号排行，也不宣称它是回答质量最好的型号。0.8B 等较新模型可后续在实际 CPU 上比较，本次不反复下载试遍。

配置：CPU 两线程、上下文 4096、最多输出 256 tokens、单请求、按需启动、空闲 30 秒卸载、不预热。普通操作不加载模型。Windows 推理进程已有低于正常的优先级；模型加载前按权重大小预留额外内存，此检查是保守估算，不是精确内存预测。

轻量模型仅用于解释，禁用模型工具调用提议；基础中文导航与确定性操作仍由规则路由处理。科学计算、浓度、权限、互锁及人工复核不交给小模型。不要把“小模型允许不精确”理解为允许错误仪器操作。

## 本轮实测

- CPU 两线程的 Mac 原生运行程序：首次加载约 12.06 秒，简单手册问答总计 12.37 秒。
- 现有 Windows 推理程序通过 Wine：加载约 3.03 秒，简单手册问答总计 10.18 秒。
- 问题为如何生成报告，回答为“完成检测后选择候选项，先复核再导出。”这里只验证运行与一个简单任务，不能推断复杂问题准确率。
- 两次测试均在开发用 Mac 上完成，存在缓存、指令翻译与系统差异，不用于比较两平台速度，也不是目标老电脑的延迟保证。真实 CPU 型号、SSD/机械硬盘及可用内存仍待确认。

原 4B 文件从活动交付目录移到源码 .qa/model-rollback 对应平台目录；源模型仍保留在 models/qwen。没有永久删除模型或用户数据。
