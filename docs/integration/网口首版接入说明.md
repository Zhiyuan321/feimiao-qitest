# 网口首版接入与联调

依据：用户提供2026-09-09提供的《质谱网口通讯协议(2).pdf》，共15页。当前是内置TCP状态回读、单包气压波形及受控调谐启停接入，可与原有485同时工作，不需要厂家插件。未完成实机和Windows 7目标系统验收。

## 在界面连接

1. 进入工作站 → 设置 → 仪器控制（代码模块名“仪器配置”）→ 运行状态 → **网口TCP**。
2. 本机IP默认 `0.0.0.0`，表示监听所有IPv4网卡；也可在下拉列表选择连接仪器的实际网卡IP。默认端口 `11000`，点击“开始监听”。如启动后更换网卡，可直接输入新的本机IP。
3. 仪器作为TCP客户端，目标地址填写电脑实际网卡IP和11000端口。**不能把0.0.0.0作为仪器目标IP**。电脑与仪器需网络可达；如Windows防火墙提示，允许此程序在仪器所在网络通信。软件不修改防火墙规则或网卡配置。
4. “正在监听”表示服务器已启动；“TCP已连接”只表示套接字已连接；收到CRC和内容均有效的状态帧才显示“网口状态回读正常”。
5. 观察倍增管高压、真空规原始值、真空度（mbar）、实验状态。真空度按2026-09-09用户确认的公式与mbar单位换算，同步显示在主界面；实验开启也不代表工作站已接入真实谱图采集。
6. “状态超时”默认5秒，可在开始监听前改为1～3600秒。这是上位机保守失效策略，协议没有规定上传周期，应按设备实际周期调整。收到其他命令的帧不能刷新状态有效期。
7. 状态超时后清空网口测量值，保持TCP等待新的状态；TCP断开后清空读数并继续监听，设备重连后必须重新收到有效状态。停止网口监听不会关闭485；断开485也不会关闭网口。
8. “导出最近报文”保存JSON：最近256条CRC有效接收帧/调谐发送帧、时间、对端IP、动作、命令、分帧字段、完整十六进制报文和计数。另附最近64条连接事件及acceptedConnections/replacedConnections/rejectedConnections计数，帮助定位旧连接未关闭时的重连。包含未解析谱图帧，但不组谱、不持久保存所有采样点。不是完整采集记录；错误CRC/帧尾/长度的字节只计入丢弃计数。

默认启动为明确标识的模拟演示，网口监听或485连接成功后才切换为真实设备回读；连接失败保留模拟展示。停止真实连接后可在运行状态页手动选择“模拟演示”，不会把断线状态悄悄伪装成模拟状态。已加载厂家插件时，内置网口/485入口不能替换插件。保存IP/端口不代表下次启动自动监听。

## 首版明确采用的协议规则

- TCP服务器角色依据第6页的QTcpServer配置，上位机监听11000；同一时刻只读取一个客户端。同一仪器IP的新连接接替旧连接（源端口可变），先使旧读数失效、丢弃旧连接半帧，再等待新连接的有效状态；其他IP的新连接在当前设备仍连接时被拒绝。IP相同不是设备身份认证，仅用于当前直连仪器的重连策略。
- 帧：`55 ACTION CMD LEN_H LEN_L COUNT INDEX PAYLOAD CRC_H CRC_L AA`。
- 第4页长度定义优先：`LEN = PAYLOAD字节数 + 2`，整帧长度 `LEN + 8`。解析器允许数据区1～1024字节；后面单个命令最大1000字节的表不会扩大状态长度。
- CRC按第5页算法：初值FFFF、反射多项式A001、无最终异或；计算范围ACTION至PAYLOAD，**CRC高字节先传**。不能套用普通Modbus线路的低字节先传规则。
- 数据多字节按大端。状态只接收 `ACTION=20、CMD=01、COUNT=1、INDEX=1、LEN=0017`，数据区恰好21字节。单帧序号1参照协议示例；其他编号保留为未解析帧，不猜布局。

| 数据区偏移（从0起） | 映射 |
| --- | --- |
| 0、1 | 大端无符号16位倍增管电压，V，范围0～3000；以第13页两字节示例为准，未采用该行U8笔误 |
| 2、3 | 大端无符号16位真空规原始值；按下述公式换算为mbar |
| 4～8 | 文档标“无用”，保留位置、忽略值，不覆盖485电源或泵状态 |
| 9 | 01=实验开启，00=实验关闭；其他值拒绝作为状态读数 |
| 10～20 | 占位，保留位置、忽略值；末尾11不能用来判断实验状态 |

第13页长度为21+2；第14页“数据区长度为23”是混用了长度字段与数据区长度。按字段表与实机报文：数据区21字节，长度字段23（0017），整帧31字节。旧14字节及旧11/12状态值不属于当前布局，不自动猜测兼容。

本地测试黄金帧（合成数据，不是实机抓包）：

`55 20 01 00 17 01 01 0B B8 04 D2 00 00 00 00 00 01 00 00 00 00 00 00 00 00 00 00 00 4C B2 AA`

期望：倍增管3000 V、真空规原始1234、实验开启。单独收到TCP连接、错误CRC、未知命令、错误数据长度或状态枚举都不构成有效状态。

## 真空度换算

2026-09-09用户补充公式，并确认pressure单位为mbar：

```cpp
result = (value * 1.0 / 65536) * 2.5 * 5.7;
pressure = pow(10, (result - 6.143) / 1.286);
```

value为网口状态偏移2、3解析后的无符号16位原始值。仅有效且未超时的状态参与换算；断线、停止、超时和连接接替时清空真空度，等待新状态。原始值0按公式计算，不将缺失数据当作0；不额外猜测故障哨兵或量程。485真空规字段是mV，不套用此ADC公式。计算保持double精度，界面使用科学计数法，JSON状态附vacuumMbar。

核对值：原始2826 → 5.02336351856E-05 mbar；原始2822～2831 → 5.01554677013E-05～5.03315158786E-05 mbar。换算的软件测试不能替代真空规实物校准。
