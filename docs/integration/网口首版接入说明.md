# 网口首版接入与联调

依据：用户提供《质谱网口通讯协议(3).pdf》，共14页。当前是内置的只读TCP状态接入，可与原有485同时工作，不需要厂家插件。未完成实机和Windows 7目标系统验收。

## 在界面连接

1. 进入工作站 → 设置 → 仪器控制（代码模块名“仪器配置”）→ 运行状态 → **网口TCP**。
2. 本机IP默认 `0.0.0.0`，表示监听所有IPv4网卡；也可在下拉列表选择连接仪器的实际网卡IP。默认端口 `11000`，点击“开始监听”。如启动后更换网卡，可直接输入新的本机IP。
3. 仪器作为TCP客户端，目标地址填写电脑实际网卡IP和11000端口。**不能把0.0.0.0作为仪器目标IP**。电脑与仪器需网络可达；如Windows防火墙提示，允许此程序在仪器所在网络通信。软件不修改防火墙规则或网卡配置。
4. “正在监听”表示服务器已启动；“TCP已连接”只表示套接字已连接；收到CRC和内容均有效的状态帧才显示“网口状态回读正常”。
5. 观察倍增管高压、真空规原始值、实验状态。真空规无单位、不转换成mbar；实验开启也不代表工作站已接入真实谱图采集。
6. “状态超时”默认5秒，可在开始监听前改为1～3600秒。这是上位机保守失效策略，协议没有规定上传周期，应按设备实际周期调整。收到其他命令的帧不能刷新状态有效期。
7. 状态超时后清空网口测量值，保持TCP等待新的状态；TCP断开后清空读数并继续监听，设备重连后必须重新收到有效状态。停止网口监听不会关闭485；断开485也不会关闭网口。
8. “导出最近报文”保存JSON：最近256条CRC有效接收帧、接收时间、对端IP、动作、命令、分帧字段、完整十六进制报文和计数。包含未解析谱图帧，但不组谱、不持久保存所有采样点。不是完整采集记录；错误CRC/帧尾/长度的字节只计入丢弃计数。

默认启动仍为模拟模式，首次点击网口监听或485连接后切换为真实只读模式。连接失败或停止后不会自动返回模拟器。已加载厂家插件时，内置网口/485入口不能替换插件。保存IP/端口不代表下次启动自动监听。

## 首版明确采用的协议规则

- TCP服务器角色依据第6页的QTcpServer配置，上位机监听11000；同一时刻只接收一个客户端，额外客户端关闭，不替换当前设备。
- 帧：`55 ACTION CMD LEN_H LEN_L COUNT INDEX PAYLOAD CRC_H CRC_L AA`。
- 第4页长度定义优先：`LEN = PAYLOAD字节数 + 2`，整帧长度 `LEN + 8`。解析器允许数据区1～1024字节；后面单个命令最大1000字节的表不会扩大状态长度。
- CRC按第5页算法：初值FFFF、反射多项式A001、无最终异或；计算范围ACTION至PAYLOAD，**CRC高字节先传**。不能套用普通Modbus线路的低字节先传规则。
- 数据多字节按大端。状态只接收 `ACTION=20、CMD=01、COUNT=1、INDEX=1、LEN=0010`，数据区恰好14字节。单帧序号1参照协议示例；其他编号保留为未解析帧，不猜布局。

| 数据区偏移（从0起） | 映射 |
| --- | --- |
| 0、1 | 大端无符号16位倍增管电压，V，范围0～3000；以第13页两字节示例为准，未采用该行U8笔误 |
| 2、3 | 大端无符号16位真空规原始值；不映射到物理气压 |
| 4～8 | 文档标“无用”，保留位置、忽略值，不覆盖485电源或泵状态 |
| 9 | 11=实验开启，12=实验关闭；其他值拒绝作为状态读数 |
| 10～13 | 占位，保留位置、忽略值 |

本地测试黄金帧（合成数据，不是实机抓包）：

`55 20 01 00 10 01 01 0B B8 04 D2 00 00 00 00 00 11 00 00 00 00 D0 96 AA`

期望：倍增管3000 V、真空规原始1234、实验开启。单独收到TCP连接、错误CRC、未知命令、错误数据长度或状态枚举都不构成有效状态。

## 本机回归与实机验收

构建 `QITestWorkstation、qitest_network_tests、qitest_rs485_tests、qitest_device_tests、qitest_ui_tests`。执行：

```text
ctest --test-dir build/win7-qt51212-release -R "qitest_(network|rs485|device)_tests" --output-on-failure
qitest_ui_tests.exe -platform offscreen networkPanelConnectsAlongside485 rs485StatusPanelReadsAndInvalidates instrumentPowerButtonsReflectPartialState
```

网络测试覆盖CRC固定向量、全切分点、粘包、噪声、CRC/帧尾/长度错误、保留字节、错误状态、TCP等待/断线/重连、读数超时、双通道独立失效、单客户端限制、原始帧缓存上限及导出。界面测试使用本机回环连接与假串口，无实机。

实机需验证：设备是否主动连接11000、是否自动上传上述14字节状态、CRC及长度是否与文档一致、读数是否随设备变化、实际上传周期、拔网线后的失效/重连；同时开启485检查温度/流量不受网口断开影响。遇到不匹配时导出报文，保留设备固件版本和现象后再修改协议，不用猜测值替代真实读数。
