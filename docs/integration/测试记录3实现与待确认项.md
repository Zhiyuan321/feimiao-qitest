# 测试记录3：本轮实现与实机核对

日期：2026-09-10。依据用户测试记录、桌面版网口协议及用户补充的旧软件气压解析代码。本轮不修改已确认的真空度、离子源电压和分子泵单位换算。

## 已实现

- 方法编辑：管理员完整参数页；普通角色仅扫描模式和进样时间。进样时间范围0～600 ms，分辨率0.01 ms。打开文件只覆盖普通角色可编辑的两项；导出和保存新版本保留原方法其他字段，控制器再次检查越权字段。仍保存为离线草稿，不启用或下发硬件。
- 仪器监控：分子泵分组显示转速、电流、电压、温度、真空度；基本信息显示载气模式、气压、载气流速、离子阱、TD温度、离子源电压、倍增器、抽气流速、注射泵剩余。泵体温度即控制器温度；离子源电压显示V。无回读字段仍显示未提供。
- 仪器配置运行状态中的“气压曲线”：0x82每两字节为无符号大端采样值，`V = raw / 65535.0 * 2.5 * 5.7`。一次展示最新单包，最多500点，保留完整数值；Y轴最低保留0～6 V，峰值超过 6 V 时自动扩展至下一个 5 V 刻度，不截断原始数值。波形有独立有效期，断线或超时后清空；样品分析页不再常驻显示该诊断页。
- 射频调谐：页面为一张图和“检测/结束”。管理员或工程师可通过控制器发送协议第7～8页的调谐开启/关闭；开启需确认、有效状态且实验停止。禁止在采集/分析或其他待确认设置期间发送。3秒等待应答，失败或超时不自动重发。超时关闭旧TCP连接、继续监听，明确设备可能仍在运行。重连后允许发送结束。

## 调谐应答边界

发送 `ACTION=10、CMD=20、COUNT=INDEX=1`，数据区22开启/23关闭；长度3，大端CRC。应答只接受同动作/命令/分帧字段、单字节11成功或12失败。应答只表示设备对命令的答复，不生成RF开关的物理回读或`settingFinished`成功。通用硬件设置仍阻止发送；当前插件ABI不变。

最近报文导出同时保留TX/RX，发送前有操作审计。本版应答等待3秒是软件策略，不是协议保证；须在实机核对ACK字节、响应延迟与调谐停止情况。若实机ACK与上述字段不同，保留原帧后再修正，不能放宽匹配来假定成功。

## 仍未确定

1. `period_ramp_waveform_time`、`gas_pressure_time`的赋值与单位；`clip_pipe_all_count`的累加和清零条件。用户代码中时间公式为 `x = 累计点号 / 1000 / 60 * (period_ramp_waveform_time / gas_pressure_time * 2)`。仅凭循环不能确定项目参数绑定和完整周期边界，因此当前X轴明确显示单包采样点序号，未伪造分钟轴。
2. 射频图的取数与mV换算，是否与0x82气压数据共用。当前收到的代码仅证明气压V换算，RF图保持待确认，不将气压波形直接当作RF。
3. 完整多包周期组装、丢包策略和离子谱图0x81转换未实现。本版气压图不用于时间积分或完整采集结果；最近256条帧只是有限联调记录。
4. 沿用现有登录/角色机制，未新增本地账户创建、密码存储或账户管理。方法权限检查不等于完成账户系统。

## 测试方式

`NetworkTests`覆盖U16大端、65535分母、非法长度、波形独立失效、启停报文、ACK拒绝、超时隔离及原有网络回读。`InstrumentControlTests`覆盖方法字段白名单与0～600 ms/0.01 ms边界。`UiSmokeTests`覆盖受限编辑、单包气压图、RF按钮和1024×768布局。

以上是合成数据和开发机测试。客户实机需要检查持续气压波形、与旧软件同点电压对照、断线失效、调谐启停应答，以及Win7 SP1实际运行。不得把本地测试当作目标系统验收。
