# 固定横屏与草案复核

## 当前布局

Windows 启动即全屏，使用当前显示器尺寸；Mac 默认以 1024×768 的 4:3 客户区窗口预览，可调整大小。两端均可用 F11 或“设置 → 系统 → 视图”切换全屏/窗口。不把固定尺寸图片拉伸到大屏，1024×768 是目标仪器屏的验收基准。

仪器端按 4:3 比例验收，不强迫其他比例的 Mac 屏幕留黑边。常用控制六个按钮均分剩余操作空间，取消其下方的弹性空白；图表区域随可用空间伸展，文字及图标保持可读尺寸。

目标为 8–9 英寸、1024×768 的横向仪器屏。窗口最小宽度 1024、高度 700；不再因宽度断点将监控变成整页。设置、内容、监控保持横向位置；助手与监控互斥打开，避免四栏挤占。主页面不整体上下滚动；数据表、对话记录及部分长编辑弹窗仍保留内部滚动，尚不能声称整个软件完全没有滚动。

设置分为仪器控制、分析校准、系统三个选择组。气路与清洗合并，离子源开关复用常用部件，不再另占菜单；硬件接入说明从菜单移除，但代码中的旧导航与协议边界仍保留。删除准备、采集、分析、复核流程装饰小字，必要说明使用 14 像素文字。射频与质量轴工作区改为固定分页。

## 低配置边界

使用 Qt Widgets 绘制，不引入网页渲染、复杂转场或背景动画。谱图数据刷新合并至约10Hz，显示绘制按像素预算处理，原始数据保留。普通操作不加载大模型；深度问答仍可能在旧CPU上缓慢，不能保证十秒以内。

Mac测试、Windows Qt5.12编译、Wine检查分别记录；均不能替代 Windows7 工控机、实际触摸屏和仪器验收。没有目标硬件，不能保证与高配置Mac具有相同帧率或响应时间。
