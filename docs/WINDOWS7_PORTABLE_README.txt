飞秒质谱工作站 · Windows 7 / Qt 5.12 · 8GB 便携运行包

1. 双击“飞秒质谱工作站安装程序.exe”完成安装。
2. 以后双击桌面“飞秒质谱工作站”快捷方式。无需编译，无需安装 Qt 或开发工具。
3. 模型和运行库由安装程序统一管理，不要单独移动内部的主程序。

系统：Windows 7 SP1 64 位、8GB 内存。32 位 Windows 7 不适用。
窗口和曲线采用 Qt Widgets 绘制，本包 AI 为 CPU 运行，不要求独立显卡。
默认低占用设置已内置，直接双击 EXE 即生效，无需配置环境变量。

已包含千问 Qwen3.5-0.8B Q4_0，不用另行下载。
模型约 563MB 是磁盘占用；进入界面不会立即把模型加载到内存。
常用页面操作走本地工具路由；开放问答才加载模型，首次回答会慢一些。
AI 最多使用 2 个 CPU 线程、单请求处理、最多 1 条等待请求；闲置 30 秒释放进程内存。
小模型只作操作说明，不负责仪器控制、定量计算或鉴定结论。
再次问答会重新加载。关闭软件后，其 AI 进程也退出。
问答过程中显示加载/生成状态和经过秒数，可点击“停止”取消本次回答。
实际速度和内存峰值取决于处理器、磁盘、其他进程与问题长度。

记录和设置写入当前 Windows 用户的数据目录，不改写随包参考谱库。
设备参数、方法参数与运行状态由统一仪器适配器提供。
第三方组件及参考数据说明在 resources\notices。

这是已经编译好的软件。“Qt5.12-源码交接包.zip”是另一份给开发人员修改、重编译的源码。
深度问答默认关闭。打开智能台不会加载模型；可明确开启“深度问答”，复杂提问时再加载。关闭立即取消推理并释放模型；本地操作说明和明确指令仍可用。
本软件已提供跨平台仪器驱动插件接口，支持参数校验、异步请求、完整回读与状态更新。
EXE 已内嵌正式图标。本交付为包含模型与运行库的一体安装包，没有商业签名，也不安装系统驱动。
