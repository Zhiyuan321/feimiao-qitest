# 用户标准的实际谱图比对

入口：设置 → 标准与校准 → 参考谱库 → 我的标准 → 选中标准 → 比对检测谱。

先在检测记录打开已有分析峰的记录。比对使用该记录已保存的检测峰（背景处理/检峰后的相对强度），不是主图游标当前扫描，不读取整个公共谱库，不运行大模型。无检测记录或无峰时给出下一步提示。

对话框固定本次标准及修订、检测峰快照，切换其他记录或更新标准不会悄悄改变已打开的比对。用户须核对离子化方式及峰表含义适合比较；软件当前没有完整的采集离子化元数据，不能自动断言二者兼容。

## 计算定义

算法版本 `qitest-reciprocal-cosine-1`。输入为递增、无重复、正 m/z、有限非负强度的峰列表，每侧最多 10000 峰，必须包含正信号。质量容差是用户指定的绝对 Da 范围，不是厂家的验证默认值。

每个检测峰寻找质量轴最近的标准峰，且该标准峰的最近检测峰必须是原峰（互为最近邻）；距离不得超过容差，等距优先较低 m/z，零强度配对不计入。每峰最多使用一次。密集/歧义峰会保守地保留部分配对，不宣称最优全局对齐。

相似度 = 配对强度乘积之和 / sqrt(全部检测峰强度平方和 × 全部标准峰强度平方和)。未匹配峰参与分母。各侧先按最大强度缩放后再平方，避免大强度数值溢出；不改变理论余弦值。展示 0–100 分，不是概率、浓度或鉴定结论，不据此自动添加候选或通过质量门控。

参考：[OpenMS SpectrumAlignmentScore 官方说明](https://openms.de/doxygen/nightly/html/classOpenMS_1_1SpectrumAlignmentScore.html) 的归一化点积形式。**本实现没有使用 OpenMS 的动态规划对齐，也不宣称与其数值完全一致**。互近邻对齐是本项目明确记录的规则。计算复杂度受峰数及二分检索约束，无二次规模距离矩阵。

## 证据与边界

可导出 `.qcompare.json`：包含算法、容差、时间、记录 ID、标准 ID/修订/来源/离子化、两侧完整输入峰、配对索引/误差、相似度和人工可比条件确认。文件带内容 SHA-256，用于完整性检查，不是身份签名。表格最多显示 500 对，导出保存全部配对；改变容差或取消确认会清除旧结果并禁用导出。原始检测数据、原报告及标准库不被修改。

当前新增的是用户标准与检测记录间的实际、可复核比对流程。方法固定标准版本、批量库搜索、MS/MS 确认和比对证据纳入正式报告仍需继续接通，不能把本功能称为全部自动鉴定能力完成。导入标准也不是对千问进行微调。

代码：`src/core/SpectralComparison.*`、`src/ui/StandardComparisonDialog.*`；页面入口在 `UserStandardsPage`，记录来源由 `MainWindow` 注入。

测试覆盖：比例一致的相同谱、已知 0.6 分值、无配对、近邻不重复使用、大数值、零信号、重复质量轴、无效容差、10000 峰边界；UI 导入→选择→条件确认→比对→导出，完整快照/摘要、参数改变后拒绝旧结果导出。
