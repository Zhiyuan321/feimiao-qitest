# 积分及校准记录契约

技术边界：本地 C++ 确定性计算，Qt Widgets；Windows 使用 Qt 5.12.12 x64。

## 校准点编辑

- 原始点以 17 位有效数字往返显示，支持科学计数法。不能通过固定小数位输入框无意改变导入值。
- 有限非负输入才可应用。拟合是否有效另行检查，允许用户保留并排除暂不能参与拟合的原点。
- 编辑窗口打开后若模型已重载或变化，拒绝旧窗口覆盖新数据。
- qcal.json 保留名称、单位、内外标、权重、原点及勾选状态；CSV 导出只包含参与拟合的点，不代替完整校准快照。

## 积分记录

入口：运行页 TIC → 提取 / 积分 → 积分记录。没有额外常驻主菜单。

`qint.json` 保存精确的提取曲线、TIC/BPC/EIC 类型、MS 级别、质量窗口、时间边界、基线方式、面积、算法标识、快照 ID 及 UTC 时间。最大 2 MiB、5000 个曲线点，不复制全部扫描或模型权重。

保存使用 QSaveFile 原子替换；失败不留下半个目标文件。改变参数后原结果失效，重新计算前不能保存。加载先解析到候选对象，通过格式、内容摘要、积分重算检查才替换状态。恢复到当前窗口还要用当前原始扫描重新提取并逐点匹配；不同记录不得仅因名称相似而套用面积。

时间输入保留精确默认端点及已加载边界；六位小数的视觉显示不应改变保存结果。手动改变对应边界后才采用新输入。

## 不宣称的能力

- 内容摘要用于检测损坏，不是电子签名或真实性认证。
- 积分文件含提取曲线，不替代原始扫描归档，不证明厂家采集定义相同。
- 面积单位是原始强度×秒。没有关联经过验证的校准前，不将其写成浓度或鉴定结论。
- 这是用户显式保存的快照，不是不可变审计数据库；未实现的批量配对、峰识别与审计撤销仍在能力差距表中。

## 回归入口

- `WorkspaceTests::integrationSnapshotsRecalculateAndRejectTampering`：精确数值往返、重算、重新计算哈希后的面积篡改、重复时间、大小上限、错误保留原状态。
- `UiSmokeTests::traceAnalysisUsesImportedScans`：参数变化禁止旧结果保存、恢复重算、不同原始扫描拒绝。
- `UiSmokeTests::calibrationEditsPreservePrecisionAndRejectStaleWrites`：原点精度、不合法数字、过期编辑。
