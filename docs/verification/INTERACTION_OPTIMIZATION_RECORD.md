# 操作与显示精修

本轮沿用既有 Qt Widgets、确定性核心和 Win7 Qt 5.12 构建链，不改变计算精度、参数边界、文件格式或仪器安全确认。

- 数值输入：统一并排减号/加号，34×32 逻辑像素点击区域，显式图标与悬停、按下、边界禁用反馈。仍由 Qt 原生 SpinBox 处理直接输入、方向键、长按、范围与小数精度。预设仅在保存时持久化，不直接下发硬件。
- 深度问答：显眼的“开启深度问答”与一句用途说明；开启只是允许复杂问题调用模型，普通导航、报告、说明检索不需要模型。关闭继续保留基本助手；现有子进程、线程限制和闲时卸载策略不变。
- 对话：原生可选中文字气泡，用户在右、浅青绿，智能台在左、浅色。输入立即显示，回答不重复追加提问。仅保留最近 80 条且总显示文字不超过 65536 字符，单条超长诊断明确截断；不把模型文本解析为 HTML，不访问外部图片，不新增磁盘聊天历史。清空立即释放控件，连续插入验证控件数量有界。
- 页面路由：参数预设和仪器控制拆成两个明确工具；“打开参数预设”进入预设输入页，不再误跳开关控制页。
- 设置导航：四个分类标题常驻，一次只展开所选分类；同一侧栏下方固定显示具体设置，不增加新列。当前模块用深青绿，具体设置用白底和浅青绿选中态区分。按实际项目数分配高度；短状态表按行高适配，避免只有几像素的滚动。长数据/长对话保留必要滚动，不以隐藏滚动条遮住内容。测试覆盖 1024×680、1280×800 所有分类的零滚动和底部可见性。
- 载气压力：从缓存遥测读取，不再把固定模拟数值当作已确认超限。可查看运行状态、展开阈值说明或直接获取本地解释；折叠说明不等于解除异常。没有厂家阈值时不建议盲目关闭气路或泵。
- 文案：候选结果统一显示“待复核”，数据来源集中标注，移除行内重复的演示修饰。保留必要的模拟来源和未经验证声明，不将模拟采集冒充真实检测。
- 稳定性：监控仅在可见且窗口未最小化时刷新缓存显示，不新增磁盘轮询或模型常驻；不为视觉效果引入动画引擎、网页壳或 GPU 依赖。

验证覆盖：Mac 和 Windows Qt 5.12 的 8 组测试，新增数值按钮命中区/上下限/键盘测试、深度模式开关、压力快捷跳转和说明折叠。UI 回归仍覆盖多次导航控件计数、双栏窄屏、方法激活与实际 PDF 输出。源码、可运行包分别交付；Wine 不替代真实 Win7 和仪器台架验证。
