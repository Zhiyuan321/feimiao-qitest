# 分栏比例：按内容预算，而非固定比例

官方设计参考：Apple [Split views](https://developer.apple.com/design/human-interface-guidelines/split-views) 的多宽度布局原则，以及 Qt [Layout Management](https://doc.qt.io/qt-6/layout.html) 的 sizeHint、minimumSize、sizePolicy 与伸缩分配。这里借鉴布局方法，不引入 Swift 或 Qt 6 专属接口；Windows 仍以 Qt 5.12 编译测试。

没有能证明所有科学软件都适用的固定“黄金比例”。本项目以控件实际可读宽度、中央空间和无重叠测试作为可验证依据；以下数值是工程设计选择，不是通用人体工学标准。

| 区域 | 逻辑像素宽度预算 | 原因 |
| --- | --- | --- |
| 智能台 | 280–320 | 两个并排快捷操作和可读对话，不随大屏无限拉宽 |
| 仪器监控 | 224–260 | 名称上排，数值与单位下排，取消内部 260 固定最小宽度，避免外栏变窄后截断 |
| 设置导航 | 176–208 | 分类与具体设置放在同一栏，避免额外再开一列 |
| 中间工作区 | 两侧并列时至少 720 | 包含设置导航后，实际编辑区仍至少约 500 |

智能台初值约为窗口宽度的 21%，监控约 17.5%，再用上述上下限约束；其余空间全部给中间内容。设置栏约取中央总宽的 1/5，同样有上下限。若双侧栏使中央不足 720，则两辅助栏改为同列上下排布，不覆盖图表、不把中央继续压缩。

例：1280 宽时，智能台 280、监控 224、中央 776；打开设置后其中导航 176，具体内容约 600（未扣内部边距）。1600 宽时，智能台 320、监控 260、中央 1020，设置导航 204。1024 宽时，两辅助栏共用 280 宽，中央仍有 744。

统一使用 Qt 逻辑像素；高 DPI 由 Qt 映射，不重复乘系统缩放。回归涵盖 1024、1152、1280、1366、1440、1600 目标宽度（受测试屏幕可用宽度限制），断言中央最小宽、编辑区预算、侧栏边界和无交叠。设置分类在 1024×680 和 1280×800 验证无需微幅滚动；长数据和聊天保留滚动。

修正后的验收还检查监控 QScrollArea 内部实际 widget 不宽于 viewport、横向滚动范围为零、子控件右边界与读数文字完整宽度。仅检查外框位置会漏掉内部裁切，不能再作为验收依据。

设置与维护使用同一棵树：模块直接列出；多页面模块在原位置向下展开，子项缩进、浅色底，当前项青绿色。单页面模块直接进入，不另建同名标题和列表。小窗口合栏时保留对话和输入，隐藏可通过对话执行的快捷提示区，智能台至少 320 高、监控至少 180 高；较长监控内容允许正常滚动。

顶部只保留“运行方法”进入运行工作区，移除重复“主页”按钮。导航本身不启动或停止采集；页面只保留质谱图旁一个开始/停止按钮，移除准备区的重复“运行当前方法”。原 OpenHome 内部路由保留兼容 AI 导航。

运行工作区取消整页 QScrollArea：上方两张谱图并排、下方全宽筛查结果，纵向伸缩预算 3:2，由控件最小高度共同约束。无结果时只显示准备区与主图；有结果时两图和结果同时可见。大量候选只在表格内部滚动，不改变仪表页高度。测试覆盖 1024×680、1280×800、1366×768 与智能台/监控四种开关组合，检查两张图和结果面板真实边界全部在窗口内，以及增加到 200 行后只有表格内部滚动。

顶部“设置｜仪器”的左右顺序与宽屏对应侧栏一致。视图可恢复默认辅助栏状态；帮助打开离线操作说明；账户页查看当前权限说明。锁屏提供应用内防误触对话框，必须通过“恢复操作”解除，明确不等于系统锁屏/身份认证；采集中禁用，并在执行前再次校验。独立清洗液抽取无厂家指令，不再共用清洗模式开关冒充执行，改为接入要求。上述操作有 UI 回归覆盖。

主要任务使用四个顶部直接入口：运行方法、编辑方法、检测记录、生成报告。参考谱库和定量曲线收纳到“设置 → 标准与校准”，保留内部工具路由，不重复创建页面。取消“数据”聚合下拉及设置中重复的文件、数据处理入口。TIC 旁的“提取 / 积分”仅在需要时打开分析面板，不新增常驻列或顶部专业按钮。采集按钮放在运行状态行，与科学图表工具区分开。

布局使用 Qt Widgets/QLayout 和代码绘制图表，并非整页位图。矢量绘制与布局适配是两件事：图标资源可缩放，控件仍需最小尺寸与实际内容边界检查。禁止以整页截图缩放、隐藏溢出或过度缩小字体替代正确重排。
