# 界面层

先按页面定位，不必通读整个 MainWindow：
- MainWindow：主窗口、导航、页面组装、状态连接。样品分析统一“开始检测”；检测中禁用按钮与操作入口，完成弹窗点击“确认”后恢复。失败/取消不弹成功提示，打开历史记录不触发完成确认。
- 实机点击开始检测先检查方法回传、真空度、离子阱温度；未达标用“检测条件未达标”弹窗列出全部原因及实测值，仅一个“确认”按钮关闭，不自动重试。通过后才打开样本信息；提交时再次检查最新读数。
- NetworkConnectionPanel / Rs485ConnectionPanel：运行状态页的网口TCP与485标签，可同时连接。网口页显示连接状态与收帧计数；无有效报文、未连接时也可导出诊断，保存结果在页面显示。导出默认TXT十六进制文本（Win7记事本可打开），也可选JSON；含TX/RX、UTC时间、完整帧和方法返回值，保留最近256条，重新监听会清空。
- Rs485ConnectionPanel同时显示主控板状态与分子泵换算值（说明保留原始值），一组COM连接按钮，支持共享收发报文导出。
- 样品分析：顶部“谱图分析 / 气压图”浅色分页。谱图分析中 TIC、质谱图和 EIC 纵向同时显示，小屏不切换隐藏其中一张。
- DeviceWaveformPanel：样品分析的“气压图”页显示网口 0x82 单包采样电压，保留采样点横轴；正常检测结束后显示“检测已结束”并保留最后一周期，下次有效检测开始时清空。仪器配置中的射频调谐启停沿用原接口，RF曲线编码/倍率仍待确认。
- 网口波形现按完整周期接收，气压页显示最近完整周期的采样电压及周期编号；不根据网络读取块大小推算采样时间。采集CRC错误会显示命令码、收到CRC和应有CRC。
- SpectrumPlot / DeviceWaveformPanel：数据到达时最多每 16 ms 合并刷新一次（约 60 Hz），空闲时不持续重绘。气压图纵轴固定0.00～6.00 V，每格1.00 V；超出范围仅裁切绘图，不修改接收数值。质谱图继续自适应量程。
- InstrumentWorkbench：质量轴等离线工作区。
- 参数预设：保留原有四项仪器参数，增加旧版默认设置中的15项检测、分析、维护及文件参数；不包含毛发参数。表单支持小屏滚动、文件浏览、本机保存和重新打开回填。这里只保存配置，不自动启动维护、不切换谱库或应用未知校正算法；检测时间以秒保存，下次实机检测读取并控制关闭时间；保存提示只确认本机配置，不声称所有参数已下发。
- MainWindow：启动后自动检查并进入工作站，不显示登录、账户或角色页面；全部功能入口可用。
- MethodEditorDialog：所有会话均显示完整方法参数，连接或断开485/TCP时字段不缩减。可保存当前版本或另存版本；已修改的当前方法须重新通过“设为当前方法”确认，非活动版本可删除。真实设备仅在设为当前方法时按 485 基本设置、网口 Fullscan 的顺序下发并等待设备应答。
- SpectrumPlot / ChromatogramDialog：谱图与提取积分。
- 样品分析和报告谱图查看的EIC显示“时间/min”“面积”，保留逐帧值连线，不显示累加值；跨帧累加仅用于后续报告阈值判定。内部扫描/点选仍用秒，CSV按显示单位导出。配置检测时长固定横轴全程范围（20秒=0.3333分钟），历史记录使用保存的时长；无时长的导入记录按真实采样范围显示。TIC仍显示秒，提取/积分窗口仍为独立的时间梯形积分，不替代直接累加筛查。
- 报告页：自动恢复最近一次已保存结果；可疑结果只列候选，筛查详情查看当前检测完整筛查面板。打开数据使用文件选择器，不触发检测完成弹窗。已移除复核入口、摘要条、质量检查区与PDF复核限制。
- ResultSpectrumDialog：当前记录快照的TIC/MS1/EIC三图弹窗，支持点选扫描、点选峰提取EIC及提取/积分；无时间序列不生成假曲线。
- 实机一级阈值筛查：可疑结果只列所有定性离子分别超阈值的物质；筛查详情显示所有库条目的定性离子、对应累加值/一级阈值和结论，悬停查看完整证据。无效条目显示未筛查。图上不显示跨帧累加结果。
- CalibrationPage：定量曲线。
- LibraryFilesPage / LibraryFileEditor：参考谱库 → 我的谱库，以 .lib 文件为一行管理；新建、导入、编辑、另存为、导出及物质增删改。九列表格可横向滚动，小屏弹窗表单可纵向滚动，按钮固定在底部。
- UserStandardsPage / StandardComparisonDialog：原用户标准及比较代码保留，历史数据库不迁移或删除。
- ChatTranscript：消息显示、清空及数量限制。
- scientz/theme：当前项目的统一样式；scientz/models：动作注册。

按钮表达操作意图；实际硬件设置必须交给 AppController，不直接写端口。
以 1024×768 小屏为主要检查尺寸；不要用大量小字、阻塞等待或动画掩盖状态。
tests/UiSmokeTests.cpp 检查交互；更改布局还需查看实际画面。

方法选择允许对已活动的方法再次“设为当前方法”，用于网口重连后的重新下发确认；活动方法仍不可删除。活动标记只代表本机选择，不代表当前连接已确认。
