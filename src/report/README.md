# 报告生成

ReportGenerator 使用已保存的分析证据生成报告，不由模型计算结果。
报告不再包含复核步骤、复核状态或复核要求；保留数据来源、筛查完成状态及可疑筛查结果的适用范围。
检查实际 PDF 的中文、分页和表头；改参数后旧证据不能继续作为当前结果输出。
对应 tests/WorkspaceTests.cpp 与 UiSmokeTests.cpp。

2026-09-18报告模板：按用户提供的检测报告版式生成A4中文PDF，列为序号、化合物名称、定量离子、是否检出，不含浓度。只列可疑候选，有完整筛查详情时再次核对对应结论，未检出/未筛查不进入结果表；无可疑项明确显示提示。定量离子取本次检测冻结谱库的quantify_ion，不用定性离子替代。被检人读取person_name，未提供的仪器/离子模式显示未提供，不照抄模板设备数据。长内容分页并重复表头。
